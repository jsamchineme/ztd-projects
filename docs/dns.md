# DNS — ztdoffice.com

Registrar and DNS host: **Namecheap** (registered 2026-10-19, renews 2027-10-19), nameservers
`dns1/dns2.registrar-servers.com`. All records below were verified live on 2026-10-19.

Verify at any time:

```bash
node scripts/check-dns.mjs
```

Host names are the short form Namecheap expects (`@` = `ztdoffice.com`). TTL is 5 minutes on
everything, so a server move takes effect quickly.

## Server addresses

| Type | Host | Value | Purpose |
|---|---|---|---|
| A | `mail` | `62.238.17.8` | Webmail and the server name clients use in Outlook/phones |
| A | `mx1` | `62.238.17.8` | Mail server; MX target for every domain we host |
| MX | `@` | `mx1.ztdoffice.com.` (priority 10) | Mail for `@ztdoffice.com` goes to the server |

Reverse DNS (set in the Hetzner Cloud console, not Namecheap): `62.238.17.8` → `mx1.ztdoffice.com`.

## TLS certificate and automatic setup

| Type | Host | Value | Purpose |
|---|---|---|---|
| CNAME | `autoconfig` | `mx1.ztdoffice.com.` | Thunderbird-style auto-setup |
| CNAME | `autodiscover` | `mx1.ztdoffice.com.` | Outlook auto-setup |
| CNAME | `mta-sts` | `mx1.ztdoffice.com.` | Serves the MTA-STS policy file |
| CNAME | `ua-auto-config` | `mx1.ztdoffice.com.` | Auto-setup used by some mail apps |

Stalwart requests one Let's Encrypt certificate covering `mx1` plus these four names. If any of
them is missing from DNS, the whole certificate request fails.
