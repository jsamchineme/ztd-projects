# ZTD Office brand assets

| File | Use |
|---|---|
| `ztdoffice-logo.svg` | Source logo (navy `#00427c`, white Z, gold `#ffc349` bar, rounded square) |
| `ztdoffice-logo-512.png` | App icons: GitHub App, Vercel, social profiles |
| `ztdoffice-logo-200.png` | Small icons |

The PNGs are rendered from the SVG with transparent corners. The webmail's iPhone icon and the
email wordmark live on the mail server in `/opt/ztdmail/branding/` (see `docs/vps-pilot.md`).
